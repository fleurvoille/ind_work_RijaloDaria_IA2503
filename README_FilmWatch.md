## 1. Теоретическая часть

FilmWatch - это веб-приложение, разработанное с использованием PHP, HTML, CSS и PostgreSQL. Оно предназначено для просмотра и управления каталогом фильмов.

PHP используется для обработки запросов пользователя, взаимодействия с базой данных и реализации серверной логики. PostgreSQL обеспечивает хранение информации о пользователях, фильмах и избранном. HTML отвечает за структуру страниц, а CSS - за оформление интерфейса.

Для подключения к базе данных используется PDO, который позволяет выполнять SQL-запросы и безопасно передавать данные.

## 2. Формулировка задачи

Необходимо разработать веб-приложение для работы с каталогом фильмов, которое позволяет пользователям регистрироваться, входить в систему, просматривать фильмы, выполнять поиск и добавлять фильмы в избранное.

Также необходимо реализовать административную часть, позволяющую управлять фильмами и пользователями.

## 3. Цель работы

Цель работы - получить практические навыки разработки динамического веб-приложения на PHP с использованием базы данных PostgreSQL, реализовать авторизацию пользователей, проверку данных, поиск информации и административное управление.

## 5. Особенности реализации приложения

Приложение имеет тёмный минималистичный интерфейс. Страницы используют общие элементы шапки и подвала, вынесенные в отдельные файлы.

Для подключения к базе данных используется PDO. Запросы выполняются с помощью подготовленных выражений.

Структура проекта разделена на отдельные папки:

- `config` - настройки подключения к базе данных;
- `includes` - общие файлы и функции;
- `admin` - административная часть;
- `assets` - стили, JavaScript и изображения.

## 6. Функциональные возможности

Приложение предоставляет следующие возможности:

- просмотр главной страницы;
- просмотр каталога фильмов;
- поиск фильмов по названию;
- просмотр подробной информации о фильме;
- регистрация нового пользователя;
- вход и выход из аккаунта;
- просмотр профиля;
- добавление и просмотр избранных фильмов;
- добавление новых фильмов администратором;
- редактирование и удаление фильмов;
- просмотр списка зарегистрированных пользователей;
- удаление пользователей администратором.

## 7. Регистрация и авторизация

Для регистрации пользователь вводит имя пользователя, электронную почту и пароль. Данные проверяются и сохраняются в таблице `users`.

Пароль сохраняется в виде хеша с помощью `password_hash()`. При входе используется `password_verify()` для проверки введённого пароля.

После успешной авторизации создаётся пользовательская сессия. Она позволяет приложению определять, вошёл ли пользователь в систему, и проверять его роль.

Для выхода используется уничтожение сессии.

## 8. Общедоступный компонент

Общедоступная часть приложения доступна без регистрации и авторизации.

Пользователь может открыть главную страницу, просмотреть каталог фильмов, ознакомиться с информацией о фильмах и воспользоваться поиском.

Данные о фильмах загружаются из базы данных PostgreSQL, поэтому содержимое страниц формируется динамически.

## 9. Создание и управление фильмами

Основным ресурсом приложения является фильм.

При добавлении фильма администратор заполняет следующие поля:

- название;
- описание;
- год выпуска;
- жанр;
- рейтинг;
- ссылка на постер;
- ссылка на трейлер.

После отправки формы данные проверяются и сохраняются в таблице `movies`.

Администратор также может открыть существующий фильм для редактирования или удалить его из каталога.

## 10. Валидация данных

В приложении предусмотрены два уровня проверки данных.

**Клиентская валидация** выполняется в браузере с помощью HTML-атрибутов форм, например `required`, `type`, `min` и `max`. Она помогает обнаружить некоторые ошибки до отправки формы.

**Серверная валидация** выполняется средствами PHP после получения данных. Проверяется наличие обязательных значений, корректность года выпуска и допустимый диапазон рейтинга.

Клиентская проверка не заменяет серверную, поскольку данные могут быть отправлены без использования браузерной формы.

## 11. Поиск фильмов

Поиск позволяет находить фильмы по названию.

Пользователь вводит название или его часть в поисковую форму. PHP получает значение из запроса и выполняет поиск в таблице `movies`.

Для поиска используется оператор `ILIKE` PostgreSQL, который позволяет выполнять поиск без учёта регистра букв.

## 12. Роль администратора и административные функции

В приложении предусмотрены две роли:

- `user` - обычный пользователь;
- `admin` - администратор.

Роль хранится в поле `role` таблицы `users`.

Административная панель доступна только пользователям с ролью `admin`.

Администратор может:

- просматривать список фильмов;
- добавлять новые фильмы;
- редактировать существующие фильмы;
- удалять фильмы;
- просматривать список пользователей;
- удалять пользователей, кроме собственной учётной записи.

Административная часть находится в папке `admin`.

## 13. Механизмы безопасности

В приложении реализованы следующие механизмы:

- хеширование паролей с помощью `password_hash()`;
- проверка пароля с помощью `password_verify()`;
- использование сессий для авторизации;
- проверка роли администратора;
- подготовленные SQL-запросы PDO для защиты от SQL-инъекций;
- серверная проверка вводимых данных;
- экранирование выводимого текста с помощью `htmlspecialchars()` для снижения риска XSS-атак;
- ограничение доступа к административным страницам.

## 14. Сценарии взаимодействия пользователей

**Сценарий 1. Просмотр каталога**

Пользователь открывает главную страницу, переходит в каталог и просматривает доступные фильмы.

**Сценарий 2. Регистрация**

Новый пользователь открывает страницу регистрации, вводит необходимые данные и создаёт аккаунт.

**Сценарий 3. Авторизация**

Зарегистрированный пользователь вводит электронную почту и пароль, после чего получает доступ к своему профилю.

**Сценарий 4. Поиск фильма**

Пользователь вводит название фильма в поисковую строку и получает подходящие результаты.

**Сценарий 5. Работа с избранным**

Авторизованный пользователь добавляет фильм в избранное и может просматривать сохранённые фильмы в отдельном разделе.

**Сценарий 6. Управление каталогом**

Администратор открывает административную панель, добавляет, редактирует или удаляет фильмы.

**Сценарий 7. Управление пользователями**

Администратор открывает список пользователей и при необходимости удаляет учётную запись.

## 15. Структура базы данных

База данных проекта называется `filmwatch` и содержит три основные таблицы.

### Таблица users

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор |
| username | Имя пользователя |
| email | Электронная почта |
| password | Хеш пароля |
| role | Роль пользователя |

### Таблица movies

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор фильма |
| title | Название |
| description | Описание |
| year | Год выпуска |
| genre | Жанр |
| rating | Рейтинг |
| poster | Ссылка на постер |
| trailer | Ссылка на трейлер |

### Таблица favorites

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор записи |
| user_id | Идентификатор пользователя |
| movie_id | Идентификатор фильма |

### Связи таблиц

- `favorites.user_id` связан с `users.id`;
- `favorites.movie_id` связан с `movies.id`.

Связь между пользователями и фильмами через таблицу `favorites` позволяет одному пользователю сохранять несколько фильмов, а одному фильму находиться в избранном у разных пользователей.


## 16. Примеры кода

### Подключение к базе данных

```php
$pdo = new PDO(
    "pgsql:host=localhost;port=5432;dbname=filmwatch",
    "postgres",
    "password"
);
```

Пример показывает создание подключения к PostgreSQL с помощью PDO. Параметры подключения должны соответствовать настройкам проекта.

### Хеширование пароля

```php
$hashedPassword = password_hash($password, PASSWORD_DEFAULT);
```

Функция `password_hash()` преобразует пароль в хеш перед сохранением в базе данных.

### Подготовленный SQL-запрос

```php
$stmt = $pdo->prepare(
    "SELECT * FROM users WHERE email = :email"
);
$stmt->execute(['email' => $email]);
```

Подготовленный запрос используется для безопасной передачи пользовательских данных в SQL-запрос.

### Проверка роли администратора

```php
function isAdmin() {
    return isset($_SESSION['role']) &&
           $_SESSION['role'] === 'admin';
}
```

Функция проверяет, имеет ли текущий пользователь права администратора.

## 17. Инструкция по запуску проекта

1. Установить Docker и запустить контейнер PostgreSQL.
2. Создать базу данных `filmwatch`.
3. Выполнить SQL-команды создания таблиц.
4. Проверить настройки подключения в `config/database.php`.
5. Открыть терминал в папке проекта.
6. Запустить PHP-сервер:

```bash
php -S localhost:8000
```

7. Открыть браузер и перейти по адресу:

`http://localhost:8000/index.php`

Административная панель:

`http://localhost:8000/admin/index.php`

## 20. Архитектура проекта

В проекте используется разделение файлов по назначению, но полноценная архитектура MVC не реализована.

Основные части проекта:

- `config` - настройки подключения к базе данных;
- `includes` - общие файлы, функции и проверка авторизации;
- `admin` - страницы административной панели;
- корневые PHP-файлы - страницы приложения;
- `assets` - стили, скрипты и изображения.

Такое разделение помогает организовать проект и повторно использовать общие элементы, однако не является полноценной реализацией MVC с отдельными моделями, представлениями и контроллерами.
